# SauceDemo E-Commerce Website | Manual Testing & QA Project

## Project Overview

This project involves manual functional testing of the SauceDemo e-commerce website to verify key shopping workflows and identify defects.

Testing covered login functionality, product display and sorting, shopping cart operations, menu options, and the checkout process.

## Tools and Technologies

- **Application Under Test:** SauceDemo
- **Browser:** Google Chrome
- **Operating System:** Windows
- **Test Documentation:** Microsoft Excel and Microsoft Word
- **Testing Techniques:** Manual functional testing, positive and negative testing, test execution, and defect reporting

## Testing Summary

- **Total Test Cases:** 70

- **Failed:** 11
- **Observations:** 1
